# Plantillas de laboratorio (1.6)

## Tools

- `list_lab_templates`
- `lab_template` con `name`:
  - `cadmio_resumen`
  - `afq_basico`
  - `cacao_lote`
- `write: true` → Word en Documentos/Informes

## Principio

Las plantillas **no inventan cifras**. El usuario/laboratorio completa los valores medidos.
