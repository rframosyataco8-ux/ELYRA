# ELYRA Changelog

## [1.0.0] — 2026-08-10 — Horizon

Primera marca de **plataforma 1.0** tras el roadmap 0.0→0.9.

### Incluye
- Asistente de escritorio Electron + voz + PC control
- LLM multi-proveedor + fallback local/web
- Memoria estructurada, RAG local, visión API
- Permisos, eval offline, harden de seguridad
- Docs: ARCHITECTURE, VOICE, RAG, FILES, VISION, EVAL, SECURITY

### Explícitamente fuera de 1.0
- Base de datos global del sistema (post-1.0, decisión del usuario)
- Entrenamiento from-scratch / multi-agent completo
